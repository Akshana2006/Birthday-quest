# Aathithya's Birthday Quest 🎮🎂

An interactive pixel-art birthday website built with React and CSS.

## Run locally

1. Install Node.js 18 or later.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

## Build for deployment

Run `npm run build`. Deploy the resulting `dist` folder to Netlify, or import this project into Vercel (framework preset: Vite).

## Personalize

- Edit `src/main.jsx` to change the letter and memory chest messages.
- Edit `src/style.css` to adjust colors, fonts, and layout.
- The game works without a backend. The Google Font requires internet access; fallback fonts work offline.

## Playable birthday garden (new)
Press START, then move Aathithya using WASD, arrow keys, or the on-screen directional buttons. Walk into all 14 hearts to unlock the next stage. Her sprite is cropped from the custom pixel-art character sheet.

Customize the final birthday letter in `src/main.jsx` and replace placeholder memories in the `memories` array.
